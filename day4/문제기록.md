# 문제 기록 — 채용 마감을 놓칠 뻔한 문제

## 1. 문제 문장

채용 공고를 사람인·원티드·인디스워크·자소설닷컴·링커리어 다섯 곳에서 따로 찾아보다 보니, 공고 마감과 지원 서류 제출일을 놓칠 뻔한다.

## 2. 5 Whys ("왜?" 기록)

| 단계 | 질문 | 내 답 |
|---|---|---|
| 왜 1 | 왜 한 곳에서 끝나지 않고 다섯 곳을 돌아다니나? | ① 사이트마다 올라오는 공고가 달라서 ② 마감일 표기가 사이트마다 달라서 ③ 내가 지원한 것과 지원할 것을 한 곳에 모으지 못해서 |
| 왜 2 | (③) 왜 한 곳에 모으지 못했나? | ① 정리하려면 내가 직접 옮겨 적어야 해서 ② 마감이 얼마 남았는지 한눈에 안 보여서 |
| 왜 3 | 왜 직접 옮겨 적어야 하나? | ① 사이트에 내보내기·캘린더 연동이 없거나 몰라서 ② 마감 표기가 제각각이라 옮기면서 내가 해석해야 해서 |
| 왜 4 | 왜 사이트들은 내보내기나 통일된 표기를 안 주나? | 채용 사이트들은 각자 자기 서비스 안에서만 쓰도록 만들어져서, 다른 곳과 합칠 공통 형식이나 공개 데이터(API)를 열어 두지 않는다. |
| 왜 5 | 그래서 내가 직접 할 수밖에 없는 일은? | 서로 다른 마감 표기("D-3", "채용 시 마감", "~10/21 18:00")를 눈으로 읽어 같은 기준으로 바꾸고, 주말·공휴일을 빼서 실제로 며칠 남았는지 계산하는 일. |

## 3. 진짜 원인 (한 줄)

마감 정보를 한 곳에 모아 같은 기준(주말·공휴일 뺀 실제 남은 날)으로 바꿔 보여 주는 내 도구가 없다.

## 4. 해결 방법 세 가지

| | A. 구글 캘린더·시트로 정리 | B. 사이트별 스크랩·알림 켜기 | **C. 내 컴퓨터(localhost)에서 도는 index.html 한 장** |
|---|---|---|---|
| 방법 | 마감을 캘린더에 적고 알림 설정, 남은 영업일은 시트 수식으로 계산 | 사람인·원티드 등 각 사이트의 알림 기능 사용 | 마감을 한 번 입력하면 표기를 통일하고, 공휴일 정보로 남은 영업일을 계산해 임박순으로 보여 줌 |
| 한 곳에 모이나 | 모임 | 안 모임 (여전히 다섯 곳) | 모임 |
| 표기 통일("채용 시 마감" 등) | 내가 해석해서 입력 | 해결 안 됨 | 입력 시 유형을 고르면 도구가 처리 |
| 공휴일 뺀 남은 날 | 공휴일 목록을 직접 관리해야 함 | 해결 안 됨 | 공휴일 데이터를 받아 자동 반영 |
| 알림 | 있음 | 있음 | 없음 (탭을 열어야 보임) |
| 만드는 수고 | 적음 | 거의 없음 | 중간 |
| 약점 | 공휴일 갱신이 수동 | 근본 원인(흩어짐) 그대로 | 입력은 여전히 직접 해야 함 |

### 선택: C

- **이유:** 진짜 원인("모으고, 같은 기준으로 바꾸고, 실제 남은 날로 보여 주는 도구가 없다")을 직접 풀고, 이번 과제의 조건(API 재료 + 로컬 index.html 한 장)에 맞는다.
- **탈락 A:** 공휴일 목록을 계속 직접 관리해야 해서 "손으로 하는 일"이 남는다. 이번 과제에서 API와 index.html을 쓰지 않는다.
- **탈락 B:** 알림은 있지만 공고가 다섯 곳에 흩어진 원인은 그대로다.
- **한계(미리 적어 둠):** C도 마감을 옮겨 적는 일을 없애지는 못하고 줄인다. 입력은 한 번만 하고, 표기 해석과 날짜 계산은 도구가 맡는다. 사이트를 자동으로 긁어오는 것은 약관과 브라우저 보안(CORS) 때문에 하지 않는다.
