# 마감 한눈에

채용 공고 마감을 **주말·공휴일을 뺀 실제 남은 영업일** 기준으로 한 화면에 모아 보여 주는 도구입니다. 서버 없이 브라우저에서 `index.html` 한 장으로 돌아갑니다.

## 문제

사람인·원티드·인디스워크·자소설닷컴·링커리어 다섯 곳에서 공고를 따로 보다 보니, 마감이나 서류 제출일을 놓칠 뻔했습니다.
사이트마다 마감 표기("D-3", "채용 시 마감", "~10/21 18:00")가 달라서 직접 읽고 같은 기준으로 바꿔야 했습니다.

## 하는 일

- 공고를 한 번 입력하면 마감 표기를 통일하고 **임박순**으로 정렬합니다.
- 마감 표기 방식 네 가지를 받습니다: 날짜와 시간 / D-n / 채용 시 마감 / 상시.
- 카드마다 **남은 영업일**과 신호등(오늘·내일 = 급함, 3영업일 이내 = 임박, 그 외 = 여유, 채용 시 마감·상시 = 확인)을 보여 줍니다.
- 달력 일수와 영업일이 다르면 이유를 함께 적습니다. 예: "달력으로는 5일, 한글날(10/9)·주말 2일 제외해 영업일로는 2일".
- 제출 목표일을 비워 두면 마감 바로 앞 영업일을 제안합니다. 상태(지원 전·작성 중·제출 완료)를 바꾸면 제출 완료는 맨 아래로 내려갑니다.
- 데이터는 이 브라우저의 `localStorage`에만 저장합니다. 서버도, 사이트 자동 수집도 없습니다.

## 실행

```bash
python -m http.server 5174
```

그다음 `http://localhost:5174/`을 엽니다. 폴더를 열고 `index.html`을 바로 열어도 되지만, 고정 파일(`fixtures/`)을 읽는 기능은 간단한 서버가 있어야 동작합니다.

| 주소 | 용도 |
|---|---|
| `/` | 실시간 공휴일(Nager.Date)로 계산. 받은 값은 하루 동안 다시 씁니다. |
| `/?fixture=1` | 인터넷 없이 `fixtures/`의 고정 파일로 계산 |
| `/?fixture=1&today=2026-10-07&time=09:00` | "오늘"도 고정해서 같은 화면을 재현 (캡처용) |
| `/tests.html` | 계산 규칙 검증 페이지 (23건) |

## 파일 구조

```
index.html     화면 뼈대
style.css      디자인 (라이트·다크, 폰 폭 대응)
rules.js       판단 규칙: 남은 영업일, 신호등, 정렬, 제출 목표일 제안 (순수 함수)
render.js      그리기: rules.js가 돌려준 결과를 화면에 옮기기만 함
api.js         공휴일 가져오기: 실시간 / 고정 파일 전환
app.js         입력·저장·화면 갱신을 이어 주는 파일
tests.html     rules.js 검증
fixtures/      실제 공휴일 응답 사본 (2026, 2027)
```

- 공휴일은 [Nager.Date](https://date.nager.at/) 공개 API(`/api/v3/PublicHolidays/{연도}/KR`, 키 없음)에서 받습니다. API가 하는 일은 "어느 날이 쉬는 날인가" 하나뿐이고, 판단은 `rules.js`가 합니다.
- 기준 시간대는 한국 표준시(Asia/Seoul)입니다. 날짜 계산은 UTC 기준으로만 해서 실행하는 PC의 시간대에 영향받지 않습니다.
- 신호등 기준(`REDCALENDARDAYS`, `ORANGEBUSINESSDAYS`)은 `rules.js` 맨 위 상수입니다.

## 확인한 것

`tests.html` 23건이 모두 통과합니다. 대표적으로 아래를 확인합니다.

- 오늘 10/7, 마감 10/12 → 달력 5일, **영업일 2일**, 한글날(10/9)이 빠진 것으로 표시
- 오늘이 공휴일(10/9)일 때, 마감 시각 전/후, 어제 마감, 설 연휴 반영
- 채용 시 마감·상시·제출 완료의 표시와 정렬 순서
- 잘못된 날짜(예: 2월 30일) 거부, D-n 변환

화면은 입력(날짜+시간, D-n), 잘못된 입력 메시지, 상태 변경 후 정렬, 실시간/고정 파일 전환을 직접 조작해서 확인했습니다.

## 일부러 안 하는 것 / 약점

- 사이트에서 마감을 자동으로 가져오지 않습니다. **입력은 여전히 직접 합니다.** (줄이는 것이지 없애는 것이 아닙니다.) 자동 수집은 약관과 브라우저 보안(CORS) 때문에 하지 않습니다.
- 알림이 없습니다. 탭을 열어야 보입니다.
- Nager.Date는 임시공휴일이 늦게 반영될 수 있습니다. 화면에 "공식 공고 확인" 문구를 붙였습니다.
- 공고 원문·합격 여부 관리는 하지 않습니다.
- 데이터가 이 브라우저에만 저장되어서 기기를 바꾸면 이어지지 않습니다.
- 폰 화면은 폭에 맞게 CSS로 대응했지만, 실제 폰에서는 직접 확인하지 못했습니다.
