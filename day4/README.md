# 마감 한눈에 (기획 문서)

채용 공고 마감을 **주말·공휴일을 뺀 실제 남은 영업일** 기준으로 한 화면에 모아 보여 주는 도구의 **기획 단계 문서**입니다. 코드는 아직 만들지 않았습니다.

## 문제

사람인·원티드·인디스워크·자소설닷컴·링커리어 다섯 곳에서 공고를 따로 보다 보니, 마감이나 서류 제출일을 놓칠 뻔했습니다.
사이트마다 마감 표기("D-3", "채용 시 마감", "~10/21 18:00")가 달라서 직접 읽고 같은 기준으로 바꿔야 했습니다.

## 계획 요약

- 마감을 한 번 입력하면 표기 유형을 통일하고 임박순으로 정렬합니다.
- 공휴일은 [Nager.Date](https://date.nager.at/) 공개 API로 받아 남은 영업일에 반영합니다.
- 규칙(`rules.js`)·표시(`render.js`)·API(`api.js`)를 분리하는 구조를 계획했습니다.

이 아이디어는 이후 "아 마따!" 프로젝트의 공고 목록 기능으로 이어졌습니다.
