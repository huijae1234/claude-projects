# 기획 한 장 — 마감 한눈에 (채용 공고 마감 모아 보기)

## 풀 문제
다섯 곳(사람인·원티드·인디스워크·자소설닷컴·링커리어)에 흩어진 채용 마감과 지원 서류 제출일을 놓칠 뻔한다.
**진짜 원인:** 마감을 한 곳에 모아 같은 기준(주말·공휴일 뺀 실제 남은 날)으로 보여 주는 내 도구가 없다. (자세한 내용: `문제기록.md`)

## 재료 (API)
- **Nager.Date** — 목록 #6, 키 없음.
- 쓰는 주소: `GET https://date.nager.at/api/v3/PublicHolidays/{연도}/KR`
- 주소창에서 먼저 확인함: 200 OK, 브라우저에서 바로 호출 가능(CORS 열림), 2026년 한국 공휴일 18건(대체공휴일 반영, `localName`에 한국어 이름).
- 쓰는 필드: `date`, `localName`. 나머지는 쓰지 않는다.
- API가 하는 일은 딱 하나: **"어느 날이 쉬는 날인가"**. 판단은 내 규칙이 한다.

## 한 장 화면 (index.html 하나, 내 컴퓨터 localhost)
1. **입력**: 회사·공고명 / 사이트(5곳 중 선택) / 마감 표기 방식 / 내 서류 제출 목표일(비우면 마감 전 마지막 영업일 제안) / 상태(지원 전·작성 중·제출 완료)
   - 마감 표기 방식: ① 날짜+시간(예: 10/21 18:00) ② D-n 표기(오늘 기준으로 날짜로 변환) ③ 채용 시 마감 ④ 상시
2. **목록**: 임박순 정렬. 카드마다 **남은 영업일**, 마감 시각, 신호등(오늘·내일 = 빨강, 3영업일 이내 = 주황, 그 외 = 초록, 채용 시 마감·상시 = 회색), 제출 완료는 맨 아래로.
3. **공휴일 반영 표시**: "달력으로는 5일, 한글날(10/9) 포함 영업일로는 2일"처럼 **왜 숫자가 다른지** 같이 보여 줌.
4. **출처 표시**: 화면 아래에 "공휴일 데이터: Nager.Date (date.nager.at) · 받은 시각 · 실시간/고정 파일" 표시.
5. 저장은 내 브라우저(localStorage). 서버 없음, 사이트 자동 수집 없음.

## 판단 규칙 (rules.js — 화면과 분리, 순수 함수)
- `남은 영업일` = 오늘 다음 날부터 마감일까지 중, 토·일·공휴일을 뺀 날 수. 마감일이 영업일이고 마감 시각 전이면 마감일도 센다.
- 마감 시각이 지났으면 "마감됨". 오늘이 마감일이면 "오늘 마감".
- 제출 목표일이 없으면: 마감일 직전 영업일을 제안.
- 신호등 기준은 파일 맨 위 상수로 둠(바꾸기 쉽게).
- 시간대는 한국 표준시(Asia/Seoul) 기준.

## 그리기 (render.js — 규칙을 호출만 함)
- 규칙이 돌려준 결과(숫자·색 이름·문구)를 DOM으로 옮기기만 한다. 판단하지 않는다.

## 파일 구조
```
day4/
  index.html          # 화면 뼈대
  rules.js            # 판단 규칙 (순수 함수)
  render.js           # 그리기
  api.js              # 공휴일 가져오기 (실시간 / 고정 파일 전환)
  fixtures/
    holidays-2026-KR.json   # 실제 응답 사본
    holidays-2027-KR.json
  기획_한장.md · 문제기록.md
```

## 고정 파일 (재현용)
- 실제 응답을 `fixtures/`에 저장해 옆에 둔다. 주소 `?fixture=1`로 열면 인터넷 없이 고정 파일로 그린다.
- 캡처는 `?fixture=1&today=2026-10-07`로 "오늘"도 고정해서 같은 화면이 나오게 한다.

## 이 화면이 일을 잘했는지 (확인 기준)
1. 다섯 곳 마감 샘플 5건을 한 화면에서 임박순으로 본다.
2. 남은 영업일이 공휴일을 뺀 값이다. (예: 오늘 10/7, 마감 10/12 → 달력 5일, 영업일 **2일**, 10/9 한글날 제외)
3. "채용 시 마감"·"상시"도 입력되고 목록에서 구분된다.
4. 입력 이후 날짜 계산에 손이 가지 않는다.
→ 마지막에 "처음 문제가 줄었나" 한 줄로 평가한다. (`문제기록.md` 5번)

## 일부러 안 하는 것 / 약점
- 사이트에서 마감을 자동으로 가져오지 않는다. **입력은 여전히 직접 한다.** (줄이는 것이지 없애는 것이 아님)
- 알림이 없다. 탭을 열어야 보인다.
- Nager.Date는 임시공휴일이 늦게 반영될 수 있다. 화면에 "공식 공고 확인" 문구를 붙인다.
- 공고 원문·합격 여부 관리는 하지 않는다.
