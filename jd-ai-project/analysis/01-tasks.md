# 01. 직무별 업무 리스트업 (생산기술 · 품질관리 · 품질보증)

> 표기: **[JD]** = 공고에 명시된 내용, **[추정]** = JD 한두 줄을 식품 제조업(라면·소스·식용유 등 대량생산) 일반 업무로 풀어쓴 것. 실제 업무는 면접·직무소개 자료로 검증 필요.

## 세 직무의 관계

```
원료 입고 → 생산(생산기술) → 제품 검사·출하 판정(품질관리) → 시장·제도 대응(품질보증)
   공정 안정화·지표        제품 분석·검수·법규 모니터링       공장 위생·업체 감사·클레임
```

## A. 생산기술 (안양/평택/음성)

### A1. 생산계획·관리 [JD: 생산관리/계획]
| 업무 | 상세 | 주 입력 → 출력 |
|---|---|---|
| 일/주/월 생산계획 수립 | 판매·재고 계획 기반 품목별 생산량·라인 배정, 설비 가동률·인력 고려 | 판매계획, 재고, 설비능력 → 생산계획표 |
| 계획 대비 실적 관리 | 계획/실적 차이 원인 파악, 일정 조정 | 일일 생산실적 → 달성률 리포트 |
| 원부자재 소요 산출·수급 확인 | BOM 기반 소요량 계산, 구매/자재팀과 납기 협의 | 생산계획, BOM → 소요량표 |
| 품목 전환(체인지오버) 계획 | 전환 횟수·시간 최소화하는 생산 순서 설계, 알레르기 교차오염 고려 | 품목 리스트 → 생산 순서 |
| 라인 간 부하 조정 | 설비 고장·수요 급변 시 대체 라인 배정 | 설비 상태 → 재배정안 |

| 업무 | 상세 |
|---|---|

| 공정 표준 관리 | 작업표준서·공정 파라미터(온도, 속도, 배합비) 설정 및 개정 [추정] |

### A3. 생산지표 관리·분석 [JD]

- 일/주/월 보고서 작성, 이상치 해석, 경영·공장장 보고 [추정]
- 라인·교대·품목별 비교 분석, 추이 모니터링 [추정]
- 현장 데이터(MES/ERP/엑셀 수기 기록) 취합·정합성 확인 [추정]

## 세 직무에 공통되는 반복 업무 (AI 후보 탐색용 메모)

1. **문서 읽기·정리**: 법규 개정, 성적서, 점검 결과, 클레임 접수문 → 사람이 읽고 요약·분류
2. **보고서 작성**: 일·주·월 지표, 점검, 부적합 보고서 → 엑셀 취합 후 수작업 서술
3. **데이터 해석**: 지표 이상 원인 추적 → 숫자는 있는데 "왜"는 사람이 파악
4. **기록 대조**: 기준(법규/규격/표준) 대비 현장 기록 비교
5. **이슈 → 원인 → 대책 사고 절차**: 5Why·파레토·재발방지, 과거 유사 사례 검색
