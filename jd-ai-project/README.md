# 식품 제조 AI 워크벤치

채용공고(JD)에서 **생산기술 · 품질관리 · 품질보증** 직무의 업무를 뽑아 정리하고, 반복되고 수작업이 많은 지점에 AI를 붙여 만든 로컬 웹 서비스입니다.
직무를 고르면 그 직무의 업무 흐름과 AI 도구만 남습니다.

> 가상의 식품회사 데이터로 만든 시연용 개인 프로젝트입니다. 실제 회사의 데이터·시스템과 무관하며, 데이터와 법규 조문은 모두 가상입니다.

## 핵심 아이디어: 코드와 AI의 역할을 나눈다

| | 하는 일 |
|---|---|
| **코드** | 숫자 계산, 이상 탐지, 그리고 AI가 한 말이 사실인지 **검증** (인용 원문 대조 등) |
| **AI** | 해석, 원인 추정, 문서 초안 |
| **사람** | 최종 판단 |

AI가 숫자를 틀리거나 없는 내용을 지어낼 수 있는 곳(법규 조문, 현장 메모, 협력업체 이력)은 코드가 원문과 글자 단위로 대조하고, 틀리면 화면에 표시합니다.

## 도구 7종

| 직무 | 도구 | 코드가 하는 일 |
|---|---|---|
| 생산기술 | 생산지표 분석·보고서 | 수율·가동률 계산, 이상치 탐지 |
| 생산기술 | 설비 이상 진단 | 정상 기준선 대비 이탈, 고장 전조 추출, 위험도 |
| 품질관리 | 검사 데이터 이상 탐지 | 관리도, Cpk, 평균 이동, 추세("N일 뒤 규격 도달" 예측) |
| 품질관리 | 부적합 보고서 초안 | AI가 인용한 메모 구절을 원문과 대조 |
| 품질관리 | 법규 개정 영향도 분석 | AI가 인용한 조문을 원문과 대조 |
| 품질보증 | 클레임 분류·회신 초안 | 입출력 스키마 검증 |
| 품질보증 | 협력업체 통보서 초안 | 메모 인용·업체 과거 이력 대조, 책임 단정 표현 경고 |

## 실행

Claude 로그인이 필요합니다(API 키는 쓰지 않습니다). 자세한 방법은 [app/README.md](app/README.md)를 보세요.

```bash
cd app
npm install
npm run dev:server   # API 서버 (터미널 1)
npm run dev:web      # 화면 (터미널 2) → http://localhost:5173
```

로그인 없이 화면만 보려면 `npm run dev:demo`를 서버 대신 실행하세요(가짜 응답, 화면 상단에 "데모 모드" 표시).

## 구성

```
analysis/       채용공고를 바탕으로 한 01 직무 업무 리스트업 → 02 문제와 AI 개선 후보 선정
tasks/          구현 계획과 진행 기록
sample-data/    유가공·육가공 가상 CSV와 "심어둔 이상"의 정답표
app/            서비스 (TypeScript · Hono · React)
```

기술: TypeScript, Hono, React, Vite, zod, vitest(테스트 114개), Claude Agent SDK(로컬 Claude 인증).

## 한계

- 데이터는 전부 가상입니다. 실제 설비·검사·법규 데이터로 검증하지 않았습니다.
- AI 결과는 초안입니다. 합격·보류 판정, 회수, 공문 발송 같은 판단은 사람이 합니다.
- 응답에 10~80초가 걸립니다(도구와 출력 길이에 따라).
