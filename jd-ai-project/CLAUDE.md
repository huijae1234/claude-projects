# JD 기반 AI 서비스 프로젝트

## 목표
JD(채용공고)를 분석해 직무 업무를 도출하고, AI로 개선 가능한 문제를 선정하여
로컬 Claude 인증(Claude Code/Agent SDK 로그인)을 활용한 UI 있는 서비스를 만든다.

## 작업 단계
1. **JD 파악**: 사용자가 붙여넣은 JD를 `jd/`에 원문 저장
2. **업무 리스트업(상세)**: `analysis/01-tasks.md` — 업무별 목적, 입력/출력, 빈도, 사용 도구
3. **문제 파악 & AI 개선 후보 선정**: `analysis/02-problems.md` — 반복·수작업·판단 병목 → AI 적합도 평가
4. **서비스 설계 & 구현**: 선정안을 로컬 Claude Auth 기반 UI 서비스로 구현 (`app/`)

## 규칙
- 한국어로 소통
- 별도 API 키 없이 로컬 Claude 인증을 사용하는 구조로 설계
