실제 회사·설비와 무관하게 만든 시연용 데이터다. 생성 스크립트: `app/scripts/gen-sample-data.ts` (시드 고정, 다시 돌려도 같은 결과).

```
npx tsx scripts/gen-sample-data.ts     # app 폴더에서 실행 → sample-data/data/ 갱신
```

## data/production_dairy_meat.csv — 라인별 일일 생산 실적 (104행)

2026년 6월, 4개 라인(우유·발효유·소시지·햄), 일요일 휴무. 기존 `seed/production.csv`와 같은 형식이라 생산지표 도구에 그대로 쓸 수 있다.

**컬럼**: `date, line, product, planned_qty, actual_qty, good_qty, defect_qty, runtime_min, downtime_min, downtime_reason, defect_note`

설비 데이터와 연결된 이상치(6건):
- 우유라인 6/9~10: 균질 불량으로 수율 하락 ← HOM-01 열화
- 우유라인 6/11: 균질기 고장으로 340분 정지, 달성률 62% ← HOM-01 고장
- 소시지라인 6/24~26: 유화 불량·케이싱 파열로 수율 하락 ← CUT-01 칼날 마모

→ 두 데이터를 같이 보면 "설비 열화 → 라인 수율 하락 → 고장 정지"로 이어지는 흐름을 확인할 수 있다.

## data/inspection_dairy_meat.csv — 검사 성적 (546행)

2026-04-01 ~ 06-30, 매일 1회 × 6개 항목. 앞 30일을 정상 기준선으로 본다. 품질관리의 "검사 데이터 이상 탐지"용.

**컬럼**: `date, lot, product, test_item, value, unit, spec_min, spec_max` (필수: date, product, test_item, value)

| 항목 | 심어둔 시나리오 | 도구가 내야 할 결과 |
|---|---|---|
| 우유 지방률 | 안정 | **정상**. 과거 일시적 관리한계 이탈 1건은 있지만 지금은 문제 없음 |
| 우유 산도 | 6/10부터 평균이 +2.7σ 올라감. 규격(≤0.18) 안 | **주의**: 평균 이동. 합격이지만 조기 경보 |
| 발효유 pH | 6/1부터 산포가 2배. 평균은 그대로 | **주의**: 산포 증가, Cpk 1.13 |
| 소시지 염도 | 6/5부터 서서히 상승. 규격 안 | **주의**: 평균 이동 + 추세, "약 48일 뒤 상한 도달" |
| 소시지 수분 | 이탈 없음. 평균이 상한 쪽에 붙어 있음 | **주의**: 이탈은 없지만 Cpk 1.27로 공정능력 부족 |
| 햄 중량 | 6/20부터 평균 −2.5g. 6/24(2건)·6/27(1건) 규격 하한 미달 | **위험 높음**: 규격 이탈 3건, Cpk 0.58, "약 4일 뒤 하한" → 부적합 보고서 필요 |

판정 규칙: 규격 이탈 / 관리한계(±3σ) 이탈 / 한쪽에 연속 8개(평균 이동) / 최근 21개 회귀 추세 / 최근 14개 산포 1.8배 / Cpk < 1.33. 최근 14개 안에 규격 이탈이 있거나 Cpk < 1.0이면 "위험 높음", 그 외 진행 중인 위반이 있으면 "주의".

## seed/ncr_memos.json — 부적합 보고서용 현장 메모 6건

일부러 짧고 불완전하게 썼다(시각·수량·담당자가 빠져 있음). 도구가 메모에 없는 정보를 지어내지 않고 되묻는지 확인하는 용도.
검사 데이터의 이상과 같은 사건을 다룬다: 소시지 금속검출기(NM-001), 우유 산도(NM-002), 햄 중량(NM-003) 외 발효유 실링 불량, 입고 케이싱, 라벨 인쇄 오류.

| 상황 | 업체 | 시험하는 것 |
|---|---|---|
| SC-001 케이싱 두께 불균일 | 새봄케이싱 | 같은 문제가 반복(SI-2025-07) → 과거 이력 인용, 공식 시정 요구 |
| SC-002 컵 실링 불량 | 대성포장산업 | **귀책 불명확**: 우리 쪽 실링 온도 변경 이력이 있음 → 업체 탓으로 단정하면 안 됨 |
| SC-003 원유 산도 상승 | 청우원유조합 | 규격 안이고 원인 모름, 이력 없음 → 상황 공유 수준 |
| SC-004 라벨 들뜸 | 미래라벨 | 과거 회신 지연(SI-2026-04) → 관련 없는 이력을 이번 원인과 연결하면 안 됨 |
| SC-005 금속검출기·향신료 | 한울향신료 | 원인 미확정, 과거 이물 이력(SI-2025-09) → 의심을 확정처럼 쓰면 안 됨 |
