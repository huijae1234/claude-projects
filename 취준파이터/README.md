# 취준 파이터 — 회의실 대난투

직무 캐릭터(개발자, 마케터, 영업, 인사팀, 디자이너, 품질팀)가 회의실에서 싸우는 **2D 대전 액션 게임**입니다. 설치 없이 `index.html` 한 파일만 브라우저로 열면 됩니다.

## 특징

- **직무별 캐릭터와 기술**: 개발자의 "버그 투척", 인사팀의 "불합격 도장", 품질팀의 "불량 경고장" 등.
- **필살기**: 체력이 40% 아래일 때 펀치+킥 동시 입력, 라운드당 1회. 연출은 직무마다 다르고(서버 다운, 대박 바이럴, 전량 폐기 처리 …) 데미지는 공통입니다. 가드 위로 들어간 필살기는 데미지가 20%로 줄어 막아서는 KO되지 않습니다.
- **CPU 상대**: 혼자서도 플레이할 수 있습니다.
- 캔버스 960×540(16:9)에 그리고 화면 크기에 맞춰 늘어납니다. 이미지 파일 없이 이모지와 도형으로만 그렸습니다.

## 실행

```bash
# 그냥 index.html 더블클릭, 또는
python -m http.server 8000
```

조작 키는 게임 시작 화면에 표시됩니다.
