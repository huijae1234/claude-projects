# izzyma 화면 설계 (초안)

기획서 기준. 이 문서는 글과 간단한 그림으로 된 설계이고, 실제 화면은 아직 만들지 않는다.

## 화면 목록 (5개)

| # | 화면 | 하는 일 |
|---|------|---------|
| 1 | 로그인 | 구글 로그인 한 번으로 시작 |
| 2 | 홈 | 오늘 할 일과 내 체크리스트를 한눈에 보기 |
| 3 | 체크리스트 상세 | 항목 체크, 항목 추가, 체크 초기화 |
| 4 | 할 일 추가·수정 | 제목, 마감일, 알림 시간 입력 |
| 5 | 틀(템플릿) | 자주 쓰는 목록(외출, 여행)을 저장하고 불러오기 |

## 이동 흐름

로그인 → 홈 → (체크리스트 상세 / 할 일 추가 / 틀)
홈이 중심이고, 나머지 화면에서 뒤로 가면 홈으로 돌아온다.

## 1. 로그인
```
      (귀여운 로고)
        izzyma
  깜빡하지 않게 챙겨줄게요

  [ 구글로 시작하기 ]
```

## 2. 홈
```
 izzyma                    (프로필)
 ─────────────────────────────
 오늘 할 일                 2/5
 ☐ 병원 예약 전화     오늘 14:00 🔔
 ☐ 택배 보내기        오늘
 ☑ 약 먹기

 내 체크리스트
 [ 외출 준비물  4/6 ]
 [ 여행 짐      0/12 ]
 [ + 새로 만들기 ]

                        [ + 할 일 ]
```
- 마감이 가까운 할 일이 위에 온다.
- 폰은 한 줄 세로 배치, 컴퓨터는 왼쪽 목록과 오른쪽 상세로 나눈다.

## 3. 체크리스트 상세
```
 ← 외출 준비물              4/6
 ─────────────────────────────
 ☑ 지갑
 ☑ 폰 충전기
 ☐ 우산
 ☐ 에어팟
 [ + 항목 추가 ]

 [ 체크 초기화 ]  [ 틀로 저장 ]
```
- 모두 체크하면 귀여운 완료 메시지를 보여준다.
- 체크 초기화는 같은 목록을 다시 쓸 때 사용한다.

## 4. 할 일 추가·수정
```
 ← 할 일 추가
 제목      [ 병원 예약 전화     ]
 마감일    [ 10월 13일         ]
 알림      [ 켜기 ] 시간 [ 13:30 ]
 구분      ( 할 일 )  ( 준비물 )

 [ 저장 ]
```

## 5. 틀(템플릿)
```
 ← 내 틀
 [ 외출 준비물 ]   [ 불러오기 ]
 [ 여행 짐     ]   [ 불러오기 ]
```
- 불러오면 체크가 모두 비어 있는 새 체크리스트가 만들어진다.

## 디자인 방향
- 둥근 모서리, 파스텔 톤, 큰 터치 영역
- 체크할 때 작은 애니메이션 (귀여운 포인트)
- 폰 먼저 설계하고 컴퓨터에서는 넓게 펼친다

## 정해야 할 것
- 알림이 폰에서 어떻게 동작할지 (웹 알림 권한, 홈 화면 추가 필요)
- 틀을 따로 화면으로 둘지, 체크리스트 상세 안에 합칠지
- 이 설계로 진행할지, 고칠 부분이 있는지
