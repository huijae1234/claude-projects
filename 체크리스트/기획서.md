# izzyma (체크리스트 앱) — 한 장 기획서

작성일: 2026-10-12

## 1. 누가 쓰나
- 나 혼자 쓴다. 공유·협업 기능은 필요 없다.

## 2. 해결할 불편
- 준비물과 짐을 챙길 때 빠뜨린다.
- 해야 할 일을 가끔 까먹는다.

## 3. 목표
- 나갈 때나 할 일을 시작할 때 목록만 열면 빠진 게 없는지 바로 확인한다.
- 같은 준비물 목록은 매번 새로 쓰지 않고 다시 쓴다.

## 4. 사용 환경
- 핸드폰과 컴퓨터 둘 다.
- 어느 쪽에서 열어도 같은 내용이 보여야 한다.

## 5. 핵심 기능 (초안)
1. 체크리스트 만들기와 항목 체크
2. 자주 쓰는 목록(외출, 여행 등)을 틀로 저장해 재사용
3. 할 일 목록과 준비물 목록 구분
4. 체크 초기화 (같은 목록을 다시 쓰기 위해)
5. 핸드폰·컴퓨터 화면 모두 대응

## 6. 하지 않을 것
- 팀 공유, 댓글, 복잡한 프로젝트 관리 기능

## 7. 확정한 것
- 동기화: 웹페이지 + 구글 로그인. 주소만 열면 폰·컴퓨터 어디서나 같은 내용.
- 마감일과 알림: 둘 다 넣는다. 할 일에 마감일을 달고, 정한 시간에 알려준다.
- 디자인 분위기: 귀여운 느낌 (둥근 모서리, 부드러운 파스텔 색).

## 8. 기능 반영 (7번 결정 후 수정)
- 핵심 기능 3번(할 일 목록)에 마감일과 알림을 추가한다.
- 6번 "하지 않을 것"에서 알림은 제외하고, 1차 범위에 포함한다.
- 알림은 웹 알림이라 폰에서는 설정과 홈 화면 추가가 필요할 수 있다. 화면 설계 전에 방식을 확인한다.

## 9. 앱 이름
- izzyma
