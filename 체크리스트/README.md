# izzyma (체크리스트 앱) — 기획 문서

준비물과 할 일을 **빠뜨리지 않게** 챙겨 주는 개인용 체크리스트 앱의 **기획·화면 설계 문서**입니다. 화면 구현은 아직 하지 않았습니다.

## 한눈에

| | |
|---|---|
| 쓰는 사람 | 나 혼자 (공유·협업 없음) |
| 해결할 불편 | 짐·준비물을 빠뜨림, 할 일을 까먹음 |
| 환경 | 폰과 컴퓨터 둘 다, 어디서 열어도 같은 내용 (웹 + 구글 로그인) |
| 핵심 기능 | 체크리스트, 틀(템플릿) 저장·재사용, 할 일과 준비물 구분, 체크 초기화, 마감일과 알림 |
| 분위기 | 귀여운 느낌 (둥근 모서리, 파스텔) |
