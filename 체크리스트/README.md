# izzyma (체크리스트 앱)

준비물과 할 일을 **빠뜨리지 않게** 챙겨 주는 개인용 체크리스트 앱입니다. 서버 없이 브라우저에서 `index.html` 한 장으로 돌아가고, 데이터는 이 브라우저에 저장합니다.

## 한눈에

| | |
|---|---|
| 쓰는 사람 | 나 혼자 (공유·협업 없음) |
| 해결할 불편 | 짐·준비물을 빠뜨림, 할 일을 까먹음 |
| 환경 | 폰과 컴퓨터 브라우저. 홈 화면에 추가해 앱처럼 쓸 수 있음 |
| 분위기 | 귀여운 느낌 (둥근 모서리, 파스텔, 체크할 때 작은 애니메이션) |

## 지금 되는 것

- **체크리스트**: 만들기, 항목 추가·삭제, 체크, 진행률(예: 4/6), 모두 체크하면 완료 메시지
- **체크 초기화**: 같은 목록을 다시 쓸 때 (한 번 더 확인하는 단계가 있음)
- **틀**: 자주 쓰는 목록을 틀로 저장하고, 불러오면 체크가 모두 비어 있는 새 목록이 만들어짐
- **할 일**: 제목, 마감일, 알림 시간. 마감이 가까운 것이 위로, 끝낸 것은 아래로
- **준비물 구분**: 할 일 추가 화면에서 "준비물"을 고르면 내 체크리스트에 항목으로 들어감
- **알림**: 마감일이 오늘이고 알림 시간이 지난 할 일을 알림(브라우저 알림 + 화면 안내)으로 알려 줌. 같은 시각에는 한 번만
- **기기 옮기기**: 설정(⚙)에서 내보내기·가져오기
- 라이트·다크 테마, 폰 폭 대응, 처음 열어 본 뒤에는 인터넷 없이도 열림(`sw.js`)

## 아직 없는 것 (기획서와 다른 점)

기획서에는 구글 로그인과 폰·컴퓨터 자동 동기화가 있었지만, **이번 구현에는 넣지 못했습니다.** 구글/Firebase 프로젝트와 키 같은 계정 설정이 필요해서입니다.

- 데이터는 **쓰는 브라우저 한 곳에만** 저장됩니다. 폰과 컴퓨터가 자동으로 같아지지 않습니다. 대신 설정의 내보내기·가져오기로 옮깁니다.
- 알림은 **이 페이지가 열려 있는 동안에만** 울립니다. 닫혀 있을 때도 받으려면 서버(푸시 알림)가 필요합니다. 폰에서는 알림 허용과 홈 화면 추가가 필요할 수 있습니다.
- 로그인 화면이 없습니다.

## 실행

```bash
python -m http.server 5175
```

그다음 `http://localhost:5175/`을 엽니다. (홈 화면 추가와 오프라인 동작은 `localhost`나 https 주소에서만 됩니다.)

| 파일 | 내용 |

| `storage.js` | 저장과 규칙: 진행률, 초기화, 틀, 할 일 정렬, 마감 표시, 알림 대상, 내보내기·가져오기 |
| `tests.html` | `storage.js` 검증 (23건) |

| [기획서.md](기획서.md), [화면설계.md](화면설계.md) | 처음 기획과 화면 설계 |

## 확인한 것

- `tests.html` 23건이 모두 통과합니다.
- 화면은 직접 조작해서 확인했습니다: 체크리스트 만들기, 항목 추가, 체크와 완료 메시지, 체크 초기화(확인 단계 포함), 틀 저장과 불러오기, 할 일 추가와 완료, 알림, 내보내기·가져오기(덮어쓰기 확인, 깨진 글 거부).
- 실제 폰과 폰의 홈 화면 추가, 푸시 알림은 확인하지 못했습니다.

이 기획은 이후 "아 마따!"(확인 기록과 재확인 추적)로 방향이 바뀌어 이어졌습니다.
