# 문제 발굴소

막연한 불편을 **풀 수 있는 문제 한 문장**으로 다듬어 주는 로컬 웹 도구입니다. 두더지 캐릭터가 질문을 한 칸씩 안내하고, 답이 쌓일수록 깊이 게이지가 내려갑니다.

## 무엇을 해 주나

- "왜?"를 여러 번 물어(5 Whys) 불편의 진짜 원인에 가까워지게 돕습니다.
- 질문과 정리는 Anthropic API(Claude)가 하고, 사용자가 답을 고치며 진행합니다.
- 한 칸에 카드 하나만 보여서 지금 할 일이 분명합니다. 라이트/다크 모드를 지원합니다.

## 구조

```
index.html   화면 전체(HTML, CSS, JS 한 파일)
server.py    로컬 서버: 브라우저는 /api/ask 만 호출하고, API 키는 서버가 .env에서만 읽음
실행.bat      Windows용 실행 스크립트
```

외부 파이썬 패키지 없이 표준 라이브러리만 씁니다. 키가 브라우저 코드나 화면에 노출되지 않습니다.

## 실행

1. [Anthropic Console](https://console.anthropic.com)에서 API 키를 발급받습니다.
2. `.env.example`을 복사해 `.env`로 만들고 키를 넣습니다. (`.env`는 저장소에 올라가지 않습니다)
3. 실행합니다.

```bash
python server.py
```

http://localhost:8765 를 엽니다. Windows에서는 `실행.bat`을 더블클릭해도 됩니다.
