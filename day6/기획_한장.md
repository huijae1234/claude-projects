# 기획 한 장 — 나한테 물어보시개! (개 품종 도감 + 퀴즈)
부제: 혹시...? 강아지 좋아하세요?

## 풀 문제
없음. 불편에서 시작한 프로젝트가 아니라 **API 두 개를 조합해 보는 개인 프로젝트**다. (`문제기록.md`)

## 재료 (API 두 개, 둘 다 키 없음)
| API | 쓰는 주소 | 하는 일 |
|---|---|---|
| **Dog CEO** | `GET https://dog.ceo/api/breed/{품종}/images/random/{n}` | 품종별 개 사진 주소 |
| **위키백과 한국어** | `GET https://ko.wikipedia.org/api/rest_v1/page/summary/{제목}` | 품종 한국어 설명 요약 |

- 주소창에서 먼저 확인함: 둘 다 200, 브라우저에서 바로 호출 가능(CORS 열림).
- Dog CEO는 품종 이름이 **영어 코드**(`retriever/golden`), 위키는 **한국어 제목**이라 서로 안 맞는다. → **직접 한 개씩 검증한 이름표**(약 80개)로 잇는다.
- 위키는 연달아 부르면 429가 난다. → 품종을 고르는 순간에만 한 번 부르고, 캐시한다.

## 한 장 화면 (index.html 하나, 내 컴퓨터 localhost)
1. **도감 탭:** 검색 + 품종 목록 → 고르면 사진 3장 + 한국어 설명 + "위키백과에서 더 보기"
2. **퀴즈 탭:** 사진 한 장 → 보기 4개 → 정답/오답 + 위키 설명 + 점수·연속 정답
3. **출처:** 사진 Dog CEO, 설명 한국어 위키백과(CC BY-SA, 문서 링크), 모드(실시간/고정 파일)를 화면에 표시

## 판단 규칙 (rules.js — 화면과 분리, 순수 함수)
- **위키 요약이 믿을 만한가**: 동음이의 문서(`disambiguation`)나 개와 상관없는 문서(예: "샤페이" → 사람 문서)는 막고, 60자 미만이면 "요약이 짧아요"로 알린다.
- 검색(공백 무시, 한국어·영어), 퀴즈 문제 만들기(보기에 같은 이름·같은 위키 문서가 겹치지 않게), 정답 판정, 점수.
- `?seed=N`으로 같은 문제 순서를 재현한다.

## 그리기 (render.js)
- 규칙 결과를 DOM으로 옮기기만 한다. 판단하지 않는다.

## 고정 파일 (재현용)
- `fixtures/`에 실제 응답을 그대로 저장: 품종 목록, 품종별 사진 3장 주소, 위키 요약(품종당), 틀린 문서 예(치와와 동음이의, 샤페이 사람 문서).
- `?fixture=1&seed=1`로 열면 같은 화면이 나온다. (사진 파일 자체는 원격이라 인터넷이 필요하다.)

## 확인 기준 (의도대로 동작하나)
1. 품종 약 80개를 사진 + 한국어 설명으로 보여 준다.
2. 이름표 전체가 규칙을 통과한다(`wrong` 0개).
3. 퀴즈 보기가 겹치지 않고, 같은 seed면 같은 순서다.
4. 위키 요청이 막혀도 앱이 깨지지 않는다.

## 일부러 안 하는 것 / 약점
- 이름표를 손으로 만들었다 → 품종을 늘리려면 하나씩 다시 검증해야 한다.
- 사진은 원격이라 오프라인에서는 안 뜬다.
- 위키 요약 길이가 품종마다 들쭉날쭉하다(짧은 것은 안내만 한다).
- 품종 자동 매칭, 사용자 사진으로 품종 판별은 하지 않는다.

## 추가: NVIDIA AI 연결

| API | 쓰는 주소 | 하는 일 |
|---|---|---|
| **NVIDIA** (키 필요) | `POST https://integrate.api.nvidia.com/v1/chat/completions` | 위키 설명을 근거로 질문에 답하기(`gpt-oss-20b`), 쉬운 말로 풀어쓰기(`llama-3.2-11b-vision-instruct`) |

- **키는 서버만 안다.** `server.py`가 `.env`에서 읽어 대신 부른다. 브라우저·화면 코드·문서·로그에는 없다.
- **근거 글은 서버가 정한다.** 화면은 품종 키와 질문만 보낸다. 서버가 검증된 위키 요약을 근거로 붙인다.
- **화면:** 품종을 고르면 설명 아래에 "AI에게 물어보기"(추천 질문 칩 5개 + 직접 입력) 와 "쉬운 말로 풀어쓰기".
- **규칙(rules.js):** 근거가 되는 위키 설명이 있을 때만 AI 사용(`canUseAi`), 질문 2~80자(`validateQuestion`), "위키에 없는 내용" 구분(`isNoEvidence`), 연타 방지(`cooldownLeft`).
- **서버 규칙:** 파일 허용 목록, 입력 검사, IP당 분당 6회·하루 200회 상한, 같은 질문 캐시.
- **실행:** `python server.py` (기본 포트 8768). 키가 없으면 AI 카드만 꺼지고 나머지는 동작한다.
- **한계와 시험 결과:** `문제기록.md`의 6번 참고. 키는 채팅에 노출됐으니 과제 후 재발급을 권장한다.
