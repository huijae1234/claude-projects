# 문제 기록 — 쉬는 시간이 통제가 안 되는 문제

## 1. 문제 문장

공부·작업 사이에 잠깐 쉬려고 하면 쉬는 시간이 통제가 안 돼서, 짧게 쉬려던 게 길어지고 집중 리듬이 깨진다.

## 2. 5 Whys ("왜?" 기록)

| 단계 | 질문 | 내 답 |
|---|---|---|
| 왜 1 | 왜 짧게 쉬려던 게 길어지나? | ① 쉬는 게 아니라 하기 싫어서 도망가는 거라서 ② 끝내고 다시 시작하는 신호가 없어서 |
| 왜 2 | (①) 왜 하기 싫어서 도망가게 되나? | ① 짧고 안전하게 숨 돌릴 수 있는 방법이 정해져 있지 않아서 ② 집중이 끝난 뒤 지친 기분을 풀 방법이 없어서 |
| 왜 3 | 왜 쉬는 방법이 준비돼 있지 않나? | ① 쉬는 건 그때그때 손에 잡히는 걸 하고 말아서 ② 짧고 끝이 있고 기분이 풀리는 것을 따로 준비해 둔 게 없어서 ③ 쉬는 게 일을 미루는 것 같아 착착히 쉰다는 생각이 없어서 |
| 왜 4 | 왜 준비해 둔 게 없나? | 쉬는 걸 "계획에 넣을 일"이 아니라 "일 사이에 남는 시간"으로만 봐서, 쉼을 위한 도구나 습관을 만들어 본 적이 없다. |
| 왜 5 | 그래서 쉴 때마다 내가 직접 해야 하는 일은? | 지친 상태에서 **무엇을 할지 고르고, 언제 끝낼지 정하고, 끝나면 돌아갈 신호를 스스로 만드는** 세 가지 결정. 이게 버거워서 가장 쉬운 폰으로 간다. |

## 3. 진짜 원인 (한 줄)

쉬는 순간에 "짧고, 끝이 정해져 있고, 기분이 풀리는" 한 가지를 대신 골라 주고, 끝나면 돌아가라고 알려 주는 것이 내게 없다.

## 4. 해결 방법 세 가지

| | A. 휴대폰 타이머·뽀모도로 앱 | B. 쉬는 거리를 종이에 미리 정해 두기 | **C. 내 컴퓨터(localhost)에서 도는 index.html 한 장** |
|---|---|---|---|
| 방법 | 25분 집중, 5분 휴식 알림 | "쉬는 시간엔 스트레칭" 같은 목록을 적어 둠 | 쉬기 버튼 → 3분 타이머 + 개그 최대 3개 + 끝나면 복귀 신호 |
| 끝을 알려 주나 | 시간은 알려 줌 | 안 알려 줌 | 시간과 개수 두 가지로 알려 줌 |
| 기분이 풀리는 걸 골라 주나 | 안 골라 줌 | 내가 골라야 함 | 개그를 대신 줌 |
| 돌아갈 신호 | 알림음뿐 | 없음 | 쉬기 전에 적은 "하던 일 한 줄"을 보여 줌 |
| 약점 | 쉬는 동안 폰을 보면 그대로 샘 | 의지에 의존 | 앱을 직접 열어야 함 |

### 선택: C

- **이유:** 진짜 원인(대신 골라 주고, 끝을 정해 주고, 돌아갈 신호를 주는 것이 없다)을 직접 풀고, 이번 과제의 조건(API 재료 + 로컬 index.html 한 장)에 맞는다.
- **탈락 A:** 시간만 알려 줄 뿐 쉬는 동안 뭘 할지는 안 정해 준다.
- **탈락 B:** 쉬는 순간 지친 상태에서 내가 직접 고르고 지켜야 해서 원인이 그대로 남는다.
- **API의 역할:** JokeAPI(키 없음)는 개그를 줄 뿐이다. 쉼을 끝내는 일(3분, 개그 3개, 복귀 신호)은 내 규칙이 맡는다.
- **한계(미리 적어 둠):** 개그는 영어로만 온다(JokeAPI는 한국어 미지원). 번역은 일부 개그에만 붙인다.

## 5. 처음 문제가 줄었나

**한 줄:** 앱 안에서는 쉼에 끝이 생겼다(3분 또는 개그 3개에서 반드시 멈추고, 쉬기 전에 적은 "하던 일"을 돌아갈 신호로 보여 준다). 다만 실제로 쉬는 시간이 줄었는지는 며칠 써 봐야 알고, 앱 밖(폰 등)으로 새는 건 막지 못한다.

### 확인한 것 (고정 파일 `?fixture=1&seed=1`, 실시간, 연결 차단 시험)
- 규칙 표 15줄 통과 (시작 직후 / 60초 / 개그 3개 / 180초 / 스스로 끝냄 / 복귀 문구 / 이력 / 같은 seed 같은 순서 등)
- 끝나는 길 세 가지가 모두 작동: 시간 끝(`?sec=6`), 개그 3개, "벌써 돌아갈래요". 끝나면 "다음 개그" 버튼이 사라진다.
- 하던 일을 적으면 복귀 화면에 그대로 나오고, 비우면 일반 문구가 나온다.
- 실시간: 요청 3건 모두 `v2.jokeapi.dev` 200. 연결을 막으면 "고정 파일로 대체"로 표시되며 계속 동작.
- 번역 있는 개그는 한국어 + 영어 원문 + 풀이, 없는 개그는 영어 + "번역 없음".
- 폰 폭(375px)에서 가로 넘침 없음, 콘솔 에러 없음.
- 캡처: `캡처/1_쉬는중_고정파일.jpg`, `2_복귀화면_고정파일.jpg`, `3_폰크기_고정파일.jpg`

### 아직 모르는 것 (솔직하게)
- 쉬는 시간이 실제로 줄었는가: 며칠 써 본 뒤 앱의 이력(쉰 횟수·평균 시간)으로 다시 본다.
- 개그를 3개 보고 나서 폰으로 새면, 이 앱은 막을 수 없다.
- 개그 대부분이 영어이고, 번역은 16개뿐이다. 실시간 모드에서 "번역 있는 개그만"을 끄면 영어만 나오는 경우가 많다.
