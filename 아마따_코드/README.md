## 저장 구조 (Artifact db)

본인 전용 경로 `data/users/<내 id>/` 안에 있다.

| 문서 | 내용 |
|---|---|
| `current` | 진행 중인 하루: 항목(`items`), 이벤트(`events`: check, uncheck, recheck, step, unstep), 시작과 종료 시각, AI 개입 끔 여부, AI 분석 글 |
| `day-<id>` | 끝낸 하루의 보관본 (기록 패널이 읽는다) |
| `templates` | 저장한 항목 템플릿 |
| `misses` | 빠뜨림 기록 (날짜를 넘어 누적) |
| `postmarks` | 공고 처리 표시 (지원 완료, 지원 안 함) |

모든 사용자가 읽는 공유 경로:

| 문서 | 내용 |
|---|---|
| `postings/p<rec_idx>` | 사람인 스크랩 공고 (회사, 직무, 마감 일시, 상태, 상세 본문) |
| `meta/postings` | 공고 갱신 시각과 출처 |

## 코드 구성 (`아마따.html` 안의 큰 덩어리)

1. CSS 토큰과 레이아웃 (노트 모양, 라이트와 다크 테마)
2. HTML 뼈대 (제목, 패널, 탭, 노트, 요약)
3. JS (한 개의 즉시 실행 함수)
   - 파생 값: 체크 상태, 재확인 횟수, 시간, 판정
   - 저장: db, 브라우저 저장, 메모리 순으로 대체
   - 동작: 체크, 취소, 재확인, 타이머, 이유, 하루 끝, 새 하루
   - AI: 재확인 개입, 확인 기준 쪼개기, 공고별 체크리스트, 하루 분석 (`sample` 사용)
   - 기록, 빠뜨림, 템플릿, 공고 목록 패널
   - 편집 모드, 키보드 단축키, 큰 화면

## 같은 와이파이로 열기 (PC에서)

`아마따_같은와이파이용.html`을 `index.html`로 이름을 바꾼 폴더에서 실행한다. 폰은 PC와 같은 와이파이여야 한다.

```bash
python -I -m http.server 8765 --bind 0.0.0.0 --directory 폴더경로
```

주소는 `http://<PC의 와이파이 IP>:8765/` 이다. 쓰고 나면 서버를 꺼야 한다.
